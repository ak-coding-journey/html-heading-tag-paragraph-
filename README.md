# html-heading-tag-paragraph-
This repository provides a beginner-friendly introduction to HTML tags. It demonstrates how different tags are used to structure and format web content, including:  Headings (&lt;h1>–&lt;h6>) – define titles and subtitles with hierarchical importance.  Paragraph (&lt;p>) – create readable blocks of text.  Text formatting – &lt;strong>, &lt;em>, &lt;br>, &lt;hr>.
