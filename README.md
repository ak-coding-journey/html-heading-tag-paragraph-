# html-heading-tag-paragraph-
This repository provides a beginner-friendly introduction to HTML tags. It demonstrates how different tags are used to structure and format web content, including: 
Headings (&lt;h1>–&lt;h6>) – define titles and subtitles with hierarchical importance. 
Paragraph (&lt;p>) – create readable blocks of text.  
Text formatting – &lt;strong>, &lt;em>, &lt;br>, &lt;hr>.

Covered Tags and Examples
Headings
<h1> to <h6> – hierarchical headings (only one <h1> per page recommended).

Paragraphs and Lines
<p> – defines a paragraph.

<br> – line break.

<hr> – horizontal rule.

Text Formatting
<strong> – bold (semantic emphasis).

<em> – italic (semantic emphasis).

<mark> – highlight text.

<small> – smaller text.

<span> – inline container for styling.

<sub> / <sup> – subscript and superscript.

<del> – deleted/strikethrough text.

<ins> – inserted/underlined text.

Code and Preformatted Text
<pre> – preserves spaces and line breaks.

<code> – monospace text for code snippets.

Quotations and Citations
<blockquote> – block quotation.

<q> – inline quotation.

<cite> – citation reference.

Special Tags
<abbr> – abbreviation with tooltip.

<bdi> – isolates text for bidirectional languages (Arabic, Hebrew).

<bdo> – overrides text direction (LTR/RTL).
